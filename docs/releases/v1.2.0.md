# v1.2.0

## What's Changed

- Updated repository documentation
- Added .editorconfig and formatted code according to styles
- Added project to share common source code between projects
- Added more tests
- Added project solely for auditing
- Improved security by storing user credentials explicitly in-memory
- Improved security by restricting user credential availability to the bare minimum required to fetch necessary data
- Improved security by using time limited encryption for user credentials
- Changed PAT expiry rule:
  - expiry beyond 180 days -> critical
  - expiry beyond 90 days -> warning
  - expiry lower than or equal to 90 days -> ok

## What's fixed

- Fixed returning the proper status code when generating a pdf and the audit was expired
- Fixed marking a user having excessive amount of PATs when amount of PATs was exactly the allowed limit

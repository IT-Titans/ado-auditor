# v1.4.1

## What's Changed

- Updated the frontend dependencies, among them Nuxt 3.21.11 and Vue 3.5.45, together with the test and build tooling. No known advisory rated critical or high is left; the remaining ones, rated moderate or low, need Nuxt 4 and Nuxt UI 4
- Every release is published to the public repository on GitHub from the pipeline, and after each production deployment the pipeline checks that GitHub holds the source of what is running. Until a deploy key is set up the release has to be published by hand and the stage is red otherwise (`docs/development/github-mirror.md`)

## What's fixed

- Fixed the forms for starting an audit and for contact inquiries being part of the server-rendered page. Submitted before the page had finished loading, such a form sent its fields as part of the address, the personal access token among them. Both forms are now created in the browser only. If you ever saw your token in the address bar, revoke it

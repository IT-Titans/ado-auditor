# v1.5.0

## What's Changed

- Moved the frontend to Nuxt 4 and Nuxt UI 4, with Vue Router 5 and Vitest 4. No known advisory is left in the frontend dependencies; 1.4.1 still had 19 rated moderate or low
- Focus rings follow the Nuxt UI 4 default, a translucent outline of 3 px in the primary colour instead of the solid ring of 2 px. Nothing else looks different
- The frontend sources moved into `frontend/app/`, the types of the backend responses into `frontend/shared/types/` (`docs/development/frontend.md`)

## What's fixed

- Fixed the rule pages for PATs and for users showing "Coming soon" instead of their rules since 1.4.1. The feature flags no longer reached the server after a dependency update, so every flag read as off
- Fixed the redirect to the canonical host and to https answering 500 instead of redirecting when `NUXT_SHOULD_REDIRECT` is set
- Fixed the landing page drawing its demo dates differently on the server and in the browser
